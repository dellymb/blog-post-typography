
# Blog Post – Typography

This project is a simple, single-page blog post website created to demonstrate how CSS typography properties can shape the appearance and readability of a web page. The design presents a sample article titled “All About Typography” and uses different text styles, sizes, and spacing to show how written content can be organized into a clear visual hierarchy.

At the top of the page, a prominent purple hero section introduces the blog post with a large title, a short explanatory paragraph, and a horizontal divider. Below it, the main article begins with a publication date and a category label. The content area uses a clean white background, dark text, and generous spacing to keep the page easy to read.

The article demonstrates several typography techniques. Its opening heading uses uppercase styling to attract attention, while selected words and CSS-related terms are highlighted in orange for emphasis. The body paragraphs use a serif font for headings and a sans-serif font for the main text, illustrating how font choices can create contrast between different content levels. A blockquote is also included, with a colored vertical border and distinct text styling to separate the quotation from the surrounding paragraphs.

The page then introduces a new content section using a horizontal rule and another heading. It shows how heading levels can be styled differently, including a title-case heading and examples of smaller headings. These examples help demonstrate how a consistent heading hierarchy makes long-form content easier to scan.

A further section, “Common Font Sizing Approaches,” explains three CSS sizing units: pixels (px), em, and rem. The page describes pixels as fixed-size values, em as a unit relative to the parent element’s font size, and rem as a unit relative to the root font size. It also discusses when responsive typography may benefit from relative units rather than fixed pixel values.

At the bottom, the layout includes footer navigation links for Privacy Policy, Terms & Conditions, About, Contact Us, and More Info. Overall, the project is a practical front-end exercise focused on typography, readable content structure, and the visual presentation of a blog article using CSS.
